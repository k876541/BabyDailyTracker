# Toddler Daily Tracker MVP 規格

## 目標

以本機優先的 iOS App，讓照顧者快速記錄幼兒飲食、睡眠、排便與成長資料，並從寶寶個人資料頁掌握最新身高、體重及歷史趨勢。

## 架構與技術

- SwiftUI + MVVM + Repository + SwiftData。
- Swift Charts 呈現成長趨勢。
- 所有資料只儲存在裝置端；MVP 不含登入、雲端同步與多人協作。

## MVP 功能

### 寶寶資料

- 顯示姓名、生日、依今日計算的年齡、最新有效身高與體重。

### 成長紀錄

- `GrowthRecord` 儲存測量日期、可選身高（cm）與可選體重（kg）。
- 支援新增、編輯、刪除與補登，列表按實際測量時間新到舊排序。
- 單筆可只填身高或體重，但至少一項；有效數值必須大於零且為有限數。
- 顯示最新值及相較前一次同類型有效測量的差異。
- Swift Charts 可切換身高／體重趨勢，圖表按測量時間排列。

### 日常紀錄

- 飲食：時間、類型、內容、備註。
- 睡眠：開始、結束、備註；結束不得早於開始。
- 排便：時間、狀態、備註。
- 三類皆支援新增、編輯、刪除及歷史列表。

## 非目標

- WHO 生長百分位、醫療判讀或建議。
- 雲端同步、帳號與跨裝置資料。

## 實作取捨

- 採單一 Swift Package App target，方便在沒有既有 Xcode 專案的空白工作區建立、測試與以 Xcode 開啟。
- Repository 封裝 SwiftData 查詢與寫入；衍生值計算保持純函式，便於測試與避免錯誤資料造成 Crash。
